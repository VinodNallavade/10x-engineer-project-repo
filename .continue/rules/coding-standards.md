---
description: Defines the Python coding standards that must be followed across the project to ensure readability, consistency, and maintainability.
---

Follow Python PEP 8 coding standards.

Requirements:
- Use Python 3.10+ features.
- Use type hints for all functions and variables.
- Maximum line length: 88 characters.
- Use clear and descriptive variable names.
- Prefer small, focused functions.
- Avoid deeply nested logic.

Formatting:
- Follow Black formatting style.
- Keep imports organized (standard → third-party → local).

Documentation:
- All functions and classes must include Google-style docstrings.
